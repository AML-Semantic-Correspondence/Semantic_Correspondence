## Introduction

This Repository is related to the project of Advanced Machine Learning, of Politecnico di Torino named as above.

The aim of the project is to indagate how much knowledge could be inferred from Visual Fondation Model for the  semantic correspondence task.  
Semantic correspondence is the objective of finding a point in an image that has the same semantic meaning of the point indicated on another image, like 2 dog noses.  
The models involved are Dinov2, DinoV3 and SAM.  
A more relatable and detailed description of the project resides in the paper pdf in this repository.

## Repository structure

The repository is thought to be easy to use on Colab.  
There is a folder named **notebooks** containing all the notebooks, with self explicative names, that just need to be uploaded on colab and executed. 
The directory is splitted into subdirectory according to the objective of the notebook, model and dataset involved.  
The other directory named **src** contains the python functions imported and called into the notebooks.
