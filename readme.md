## Introduction

This Repository is related to the project of Advanced Machine Learning course @ Politecnico di Torino named as above.

The aim of the project is to indagate how much knowledge can be inferred from Visual Fondation Models for a semantic correspondence task.  
Semantic correspondence is the objective of finding a point in a target image that has the same semantic meaning as the point indicated on a source image.
The models involved are DINOv2, DINOv3 and SAM.  
A more reliable and detailed description of the project resides in the pdf report stored in this repository.

## Repository structure

The repository is thought to be easy to use on Colab.  
There is a folder named **notebooks** containing all the notebooks, with self explicative names, that just need to be uploaded on colab and executed.  This directory is splitted into subdirectories according to the objective of the notebook, model and dataset involved.  
The other directory named **src** contains the python functions imported and called into the notebooks.
